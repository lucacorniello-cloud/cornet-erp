## Command Palette

Scorciatoia:

- macOS: `⌘K`
- Windows: `Ctrl+K`

Azioni:

- ricerca globale;
- apertura cliente;
- apertura contratto;
- nuova pratica;
- importazione PDC;
- nuova riparazione;
- nuova attività;
- accesso a viste salvate.
