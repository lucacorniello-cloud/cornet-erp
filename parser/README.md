# Parser PDC

Modulo dedicato a:

- classificazione documento;
- estrazione testo;
- OCR;
- riconoscimento operatore;
- estrazione campi;
- normalizzazione;
- confidenza;
- provenienza del campo;
- confronto duplicati.

Ogni campo estratto deve conservare:

- valore originale;
- valore normalizzato;
- pagina;
- bounding box quando disponibile;
- regola usata;
- confidenza;
- avvisi.
