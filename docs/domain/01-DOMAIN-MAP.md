# Domain Map

## Core domains

### CRM

Gestisce clienti, aziende, referenti, contatti, indirizzi, tag, note e relazioni.

### Contracts

Gestisce contratti, categorie, operatori, linee, numerazioni, SIM, offerte e stato.

### Services

Gestisce Office Plus, backup, PEC, centralini, MDM, FWA, opzioni e licenze.

### Practices

Gestisce workflow operativi: attivazioni, migrazioni, subentri, volture,
portabilità, recessi, assistenza e variazioni.

### Imports

Gestisce file PDC, parser, OCR, confronto duplicati e importazione guidata.
