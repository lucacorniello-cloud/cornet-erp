# Design System

## Principi

- professionale;
- leggibile;
- elevata densità informativa senza affollamento;
- coerenza visiva;
- interazioni prevedibili;
- accessibilità;
- responsive;
- light e dark mode.

## Componenti obbligatori

- App Shell
- Sidebar
- Topbar
- Command Palette
- Universal Search
- KPI Card
- Data Table
- Filter Bar
- Entity Header
- Tabs
- Timeline
- Activity Composer
- Drawer
- Modal
- Stepper
- Dropzone
- Diff Viewer
- Confidence Meter
- Status Badge
- Empty State
- Error State
- Skeleton
- Toast
- Confirm Dialog

## Token

- spacing: 4, 8, 12, 16, 24, 32, 48;
- radius: 8, 12, 16;
- typography: 12, 14, 16, 20, 24, 32;
- elevation: subtle, medium, overlay;
- semantic colors: primary, success, warning, danger, info, neutral.

## Regola schermate

Ogni dominio deve avere:

1. elenco;
2. dettaglio;
3. creazione;
4. modifica;
5. ricerca;
6. filtri;
7. timeline;
8. audit;
9. stato vuoto;
10. stato errore.
